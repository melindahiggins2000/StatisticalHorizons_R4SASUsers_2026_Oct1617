1. Install R

NoteR versus RStudio

Note: R is the name of the programming language itself and RStudio is an integrated development environment (IDE) which is an enhanced interface for better organization, files management and analysis workflows.

Download R from CRAN

The R programming language is maintained and distributed by CRAN The Comprehensive R Archive Network. They provide the installers for the binary distributions of the base system and contributed packages. R is FREE!

Installation Instructions are provided for these operating systems:

  • Windows
    • Choose “base” and I suggest you accept the default installation options.
    • OPTIONAL - You may also want “RTools” if you think you may want to do build your own R packages in the future. This is NOT needed for this course.
  • Mac
    • Please make note of the specific details on which installer you may need for your version of Mac OS (operating system).
    • I work on a Windows operating system, so please reach out to your local IT support for help getting the correct version installed for your system.
  • Linux
    • Odds are you are probably using either Windows or Mac OS, but if you using Linux, please read carefully the specific details for your version of Linux.

2. Install RStudio Desktop

ImportantInstall R First and RStudio Second

It is important to install the R programming language FIRST. I also encourage you to use the default installation options, so that when you install the RStudio Desktop application, it will “know” where (folder locations) to look for your R installation.

The RStudio IDE (integrated development environment) software is developed and distributed by the POSIT Company, which was formerly known as “RStudio” founded in 2009. In 2022 they changed their name to “Posit”, however, the name of the software application stayed “RStudio”.

For this course, we will be using the RStudio Desktop software. RStudio Desktop is FREE. The “PRO” version does cost money.

You can download RStudio Desktop from https://posit.co/download/rstudio-desktop/.

I think the website link above will “autodetect” which operating system you have. Mine defaults to the Windows installer.

However, if you have a Mac you should get the installer for the Mac OS. Regardless, you can always choose the operating system and version you need.

And if you keep scrolling down the webpage you can find older versions of RStudio if/as needed as well.

NoteRStudio or Positron?

For this course, I will use the RStudio IDE. However, there is a newer alternative to “RStudio”, known as “Positron” which was released in 2025.

Learn more about Positron. Positron is also an IDE programming environment, but is designed to accommodate multiple programming environments and multiple sessions at the same time, e.g. you can run both R and Python and manage multiple versions at one time. We will NOT cover these details in this course.

Technically, you can also use the RStudio IDE to execute and manage Python programs as well. In fact RStudio can help manage several other programming languages as well.

To install these packages, the easiest way is to use the RStudio Menu “Tools/Install” Packages interface:

For example, let’s install a “new” R package, like ggplot2.

Go to the RStudio menu “Tools/Install” Packages

This will then open up a window where you can type in the name of the package you want. As soon as we start typing ggplot2 the menu begins listing all packages with that partial spelling…

You’ll notice that there are 3 parts to the installation:

  1. Where you want to get the package from (i.e., which repository - more on repositories later in this course).
  2. The name of the package. You can actually type more than one package name at a time separated by commas if you want to install several packages at once.
  3. The file location on your computer where the new package is installed - your file location will be different than mine. But this is useful to know in case something goes wrong. I would suggest keeping the default settings.

After installing ggplot2 you should see ggplot2 listed under the Packages window:

Repeat this process to install the rest of the R packages needed.

Note: You can also confirm the installation of the R packages on your computer by going to the folder listed under #3 “Install to library” path listed above – on my computer my R packages are in this folder on my computer C:\Users\mkhiggi\AppData\Local\R\win-library\4.6.

4. Run Quick Check

Let’s confirm that your installation of R, RStudio and your packages are working. For example, let’s test that your installation of ggplot2 is working. Run the following R code as a quick test.

library(ggplot2)
ggplot(pressure, aes(temperature, pressure)) +
  geom_point()

6. Create New RStudio Project

Start RStudio and then Click on “File/New Project”.

You have 3 options here:

  • New Directory
    • if the project folder does not exist yet
    • this is useful for more complicated “projects” like creating website or R packages
  • Existing Directory
    • use this option if the folder where all of your project files are stored already exists
  • Version Control
    • use this option if you want to bring your project under version control using Github or Subversion Control (SVN).

We will use “Existing Directory” since you have already created the project folder on your computer and put your files in there.

Next you need to select the existing project folder on your computer (or cloud or networked drive) - click “Browse”

Then go find the folder and click “Open”.

Now check that your “Project working directory” matches the folder you selected - on my computer this is C:\R4SASUsers. Then click “Create Project” to create a new RStudio project.

Your new RStudio project should look like this. Check the folder location at the top left of your window. Also check that this is the SAME folder shown in the “Files” tab at the bottom right window. In this “Files” window, you should see the files you copied over from what you downloaded from the “FilesForRProject” folder from the Google Drive R4SASUsers_Oct2026 for this workshop.
